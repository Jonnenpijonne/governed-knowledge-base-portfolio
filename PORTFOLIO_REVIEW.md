# Portfolio publication review

Tämä tiedosto on tarkistuslista ennen repon mahdollista muuttamista julkiseksi.

- [ ] Koko nykyinen tiedostopuu tarkistettu
- [ ] Koko git-historia tarkistettu
- [ ] Automaattinen validaattori ja testit läpäisevät
- [ ] GitHub Actions -lokit eivät sisällä luottamuksellista tietoa
- [ ] Ei yritysten, asiakkaiden tai henkilöiden nimiä
- [ ] Ei todellisia tunnuksia, domaineja, URL-osoitteita tai aineistorivejä
- [ ] Tekijyys ja clean-room-luonne kuvattu READMEssä
- [ ] Lisenssi soveltuu julkaisuun
- [ ] Mahdollinen työnantajan hyväksyntä saatu, jos sitä vaaditaan

Yksityinen repo ei tee luottamuksellisesta aineistosta turvallista julkaistavaa.
Julkisuus muutetaan vasta, kun kaikki kohdat on erikseen vahvistettu.
